TECHNIQUE AND PLATFORM RENDERS
------------------------------
In the 'technique figures' subfolder.
Added for the methodology slides and the per-technique backup slides.
All of these are own work, rendered from the Unity project. No credit line needed.

  platform_1_mixamo / _2_meta_sdk / _3_avaturn
      The three baseline avatars, no NPR applied.

  technique_V1_silhouette_*     inverted hull outline
  technique_V2_toon_*           quantised diffuse bands
  technique_V2-2_xtoon_*        2D ramp, plus two ramp sweeps
  technique_V3_normal_edges_*   screen-space normal derivatives
  technique_V4_sobel_*          colour-buffer gradient, plus a raised-threshold version
  technique_V4-2_gaussian_*     Gaussian prefiltered Sobel
  technique_V5_hierarchical_*   depth, normal and colour layers merged
  technique_V6_kuwahara_*       anisotropic painterly filter

The suffix is the platform: mixamo_jody, meta_sdk or avaturn.

'mixamo_jody' is one platform, not two. Mixamo is the platform and Jody is the
character on it, and the thesis uses both words, so both are in the filename.
There is no separate '_jody' file to look for.

ALL THREE PLATFORMS ARE PRESENT FOR ALL EIGHT TECHNIQUES (24 files). The set is
the same one the thesis uses in Chapter 4, copied file for file, so a backup
slide and the corresponding thesis figure always show the identical render.
The Meta SDK figures live in thesis/figures/mataAvatars/, not thesis/figures/Meta/,
which is why an earlier version of the deck was missing several of them.

Two exceptions worth knowing:
  - V2.2 X-Toon, V3, V4, V4.2 and V5 take the Mixamo column from the Jade/
    folder, since Jody is the Mixamo character. V1, V2 and V6 take it from
    Mixamo/. Either way the file here is named _mixamo_jody.
  - technique_V5_hierarchical_sweep_mixamo_jody is the 4-panel threshold sweep.
    It is NOT the same image as technique_V5_hierarchical_mixamo_jody, which is
    the square 3-platform comparison. Both are kept.
  - technique_V2-2_xtoon_ramp_* are the ramp sweeps, separate from the
    _xtoon_* platform comparisons.
  - technique_V4_sobel_raised_threshold_avaturn is the higher-threshold variant.

Showing one technique across platforms is the RQ1 evidence: same operator,
different pipeline, visibly different output.

Source folder for all of them: thesis/figures/{Mixamo,Meta,Avaturn,Jade}/
